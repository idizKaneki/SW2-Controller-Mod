# Samurai Warriors 2 (PC) - Controller Mod (Xbox / PlayStation)

Source code of the Nexus Mods release:
https://www.nexusmods.com/samuraiwarriors2/mods/8

Western console button layout, right stick camera, A/Cross confirms in menus,
and controller button icons instead of keyboard keys. No game file is included.

## What SW2Controller.asi does

It is loaded by the ASI loader and patches the game **in memory only**
(`sw2.exe` is never modified). Each patch first checks the exact original bytes
and is skipped if they do not match. Everything is logged to `SW2Controller.log`
and each part can be turned off in `SW2Controller.ini`.

- **RightStick**: the game only read as many axes as the controller reports
  (5 on an Xbox pad), so the right stick X axis was ignored. The game now reads all 8 DirectInput axes.
- **MenuConfirmA**: swaps two entries of the menu action table, so Jump (A) confirms and Musou (B) cancels in menus.
- **NoAutoSetup**: skips the "Use the gamepad's auto-setting?" question in the button settings screen.
- **RotateRightStick**: in the game's text data, the "rotate" prompt uses a free icon slot (right stick icon).

No network access, no file written except `SW2Controller.log` in the game folder.

The Python scripts only:
- `sw2_controller.py`: write the game's own controller settings (`Documents\KOEI\SAMURAI WARRIORS 2\inputmap1.dat / inputmap2.dat`), keeping a backup of the originals;
- `sw2_icons.py`: patch the button icon texture inside `linkdata\LINKDATA_BNS_NA.lnk`, in place, after checking its md5.

## Build

### SW2Controller.asi
32-bit Windows DLL (renamed .asi), built with the standard MinGW C runtime and a version resource (`version.rc`).
Needs [Zig](https://ziglang.org) (tested, `zig cc`) or MinGW-w64 32-bit (e.g. MSYS2 "MINGW32" shell).

    cd src
    build.bat         (Windows)
    ./build.sh        (Linux / macOS)

Zig command used for the release:

    zig cc -target x86-windows-gnu -O2 -s -shared -o SW2Controller.asi sw2controller.c version.rc -lkernel32 -Wl,--subsystem,windows

### Icon patches
Needs Python 3 + Pillow 12 + numpy, and the game's icon sheet (BNS entry 43, extracted from
your own copy of the game; not included):

    python build_tools/icons_build.py 00043.bin out

### Release zip

    python build_tools/creer_mod_controller.py python-3.x.y-embed-amd64.zip dinput8.dll --version 1.0.1

(expects `INSTALL.bat`, `UNINSTALL.bat`, `readme.txt`, `files/` and `tools/` next to it: copy the
contents of `package/` and the built `SW2Controller.asi` into `files/` first).
